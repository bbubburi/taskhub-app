# 내투두

할 일·일정·자료(링크·메모·사진·파일)를 한곳에서 관리하는 개인용 웹앱입니다. 폰과 PC 브라우저에서 같은 화면으로 열립니다.

- 데이터는 서버로 전송되지 않고 사용하는 기기의 브라우저에만 저장됩니다. 로그인도 없습니다.
- 기기를 바꾸거나 브라우저 데이터를 지우면 사라지므로, 앱 안의 `⋯ → 백업 · 복원`에서 정기적으로 파일로 저장해 두세요.
- 폰은 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

## 글꼴

고운돋움(Gowun Dodum)과 주아(Jua)를 사용하며, 둘 다 SIL Open Font License 1.1 입니다. 라이선스 전문은 `app/fonts/` 에 있습니다.
